About

This project is an automated houseplant watering system built with an ESP32. It monitors soil moisture through sensors and automatically waters the plant when needed, with planned support for monitoring and control via both a mobile app and web interface.

The project was created to help me explore embedded programming while also bringing me closer to my goal of being a great plant mom. I had been interested in IoT projects for some time, and this felt like a fun and interactive idea to finally dive in. Through this project, I am familiarizing myself with topics I had previously not worked with, including electronics and embedded programming.

Future Plans

This project is a work in progress, but the goal is to develop it into a fully functioning irrigation system for a houseplant. The ESP32 will process input from a soil moisture sensor and control a water pump to supply the appropriate amount of water. In the future, the plant parent will be able to monitor the moisture level and control the watering behavior through both a mobile application and a web interface.

What I Am Learning

Working with electronics and designing a safe and functional environment for the different components has been a rewarding learning experience. Programming an ESP32, getting to understand its inner workings, writing code that works in harmony with the scheduler, and finally seeing the individual components communicate with each other has been both challenging and immensely satisfying. Finally, I am developing this project in a Linux environment, which has pushed me to work more closely with computers and deepen my overall technical understanding.
